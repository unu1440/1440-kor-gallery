# 템플릿 서체

템플릿 미리보기에서만 쓰는 한글 서체입니다. 모두 SIL Open Font License 1.1이고, 라이선스 원문은 같은 폴더의 `*.LICENSE`에 있습니다.
파일은 KS X 1001 한글 2,350자 서브셋입니다(`research/cargo-benchmark/fonts/sub/`에서 복사).

| 파일 | 서체 | 만든 곳 |
|---|---|---|
| `SUIT.woff2` | SUIT | SUNN |
| `MaruBuri-Regular.woff2`, `MaruBuri-Bold.woff2` | 마루 부리 | NAVER |
| `Galmuri11.woff2`, `Galmuri11-Bold.woff2` | 갈무리11 | 이민서 |
